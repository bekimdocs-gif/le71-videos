# LE 71 Flash News

Hébergement des vidéos TikTok de **LE 71 Flash News** (@flashnews71000), l'actualité de la Saône-et-Loire présentée par Léa.

- `videos/AAAA-MM/` : vidéos publiées
- `episodes/AAAA-MM/` : épisodes (JSON) et descriptifs
- `HISTORIQUE.md` : journal des publications
- `STATS.md` : relevés statistiques
- `LECONS.md` : ce qui fonctionne / ce qui est à corriger

- `production/` : moteur vidéo (`le71.py`, `d71.json`, `setup.sh`) et guide de production — **version de référence**, utilisée par les tâches programmées
